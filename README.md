# シナモンのそらとぶだいぼうけん 🌟

ふわふわのこいぬ「シナモン」を操作して空を飛ぶゲームです。

## あそびかた

`index.html` をブラウザで開くだけで遊べます。

- **タップ** または **スペースキー / ↑キー** で羽ばたいて上昇
- ⭐ 星を集めるとスコア +1
- 🥐 シナモンロールを取るとボーナス +5
- ⛈️ 怒った雨雲にぶつかるとハートが減る(ハート3つでゲームオーバー)
- スコアが増えるほどスピードアップ!

ベストスコアはブラウザに自動保存されます。

## 動作環境

- 追加インストール不要(HTML + Canvas + Web Audio のみ)
- PC・スマホ両対応
